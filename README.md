## 🌟 Mainframe Projects

### 🏦 CICSBankLedger – Transaction & Account Management System

A **complete banking system simulation** built using COBOL, CICS, VSAM, and JCL, focusing on real-world transaction flows.

#### 🔹 Key Features:

* 💳 Online payment processing via CICS screens
* 🏦 Account and customer management (CRUD operations)
* 📜 Transaction ledger to track all activities
* 🔄 Batch processing for:

  * Daily payment updates
  * Delinquency calculation
  * Report generation

#### 🔹 Technical Highlights:

* VSAM KSDS operations (READ, REWRITE, STARTBR, READNEXT)
* TSQ-based pagination (PF7/PF8 navigation)
* File splitting into Paid and Delinquent records
* Integration of batch and online systems

---

### 🏦 CoreLend – CICS Loan & Payment Processing System

An enhanced **mainframe banking application** designed with structured batch flows and reporting mechanisms.

#### 🔹 Key Features:

* 💳 Handling of Exact, Partial, and Excess payments
* 📂 Daily target and payment file processing
* 🔄 Batch workflows including:

  * KSDS file updates using keyed access
  * File merging and transformation
  * Delinquency tracking and classification
* 📊 Report generation with header/trailer formatting

#### 🔹 Technical Highlights:

* Advanced use of VSAM KSDS (READ, REWRITE, sequential + dynamic access)
* Use of GDG for daily fresh datasets
* JCL-based data pipeline (REPRO, SORT, MERGE)
* Column-level transformations using SORT (OUTREC/OUTFIL)
* Clean separation of **data processing vs reporting layers**
